# MJ ASSET — ระบบทะเบียนบริหารทรัพย์สิน (หน้าเว็บ GitHub Pages)

Major Property Service · ฝ่ายธุรการและประชาสัมพันธ์ (ADM-PR)

หน้าเว็บสำหรับผู้ดูแลระบบและเจ้าหน้าที่หน่วยงาน ใช้จัดการทะเบียนทรัพย์สิน นำเข้ารูปจาก Google Drive ทำ QR PDF และรายงาน PDF / Excel · ติดตั้งเป็นแอปบนมือถือได้ (PWA)

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ (หน้าตา + สไตล์ + โลโก้) |
| `app.js` | โปรแกรมหน้าเว็บ |
| `config.js` | **ตั้งค่าลิงก์ Apps Script** (แก้ไฟล์นี้ไฟล์เดียว) |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | ทำให้ติดตั้งเป็นแอปบนมือถือได้ |
| `favicon.svg`, `404.html`, `.nojekyll` | ไอคอนสำรอง หน้าไม่พบ และปิด Jekyll |

ระบบเบื้องหลัง: Google Apps Script (Drive + ส่งอีเมล) และฐานข้อมูล Supabase

## ความปลอดภัย

- ไฟล์ในนี้ **ไม่มีรหัสผ่านหรือ token** — รหัส API เก็บอยู่ใน Apps Script เท่านั้น ห้ามอัปโหลด `Code.gs` ขึ้น GitHub
- ทุกคำสั่งต้องล็อกอินด้วยบัญชีของระบบ ผู้ใช้หน่วยงานเห็นเฉพาะหน่วยงานของตัวเอง

## อัปเดตหน้าเว็บ

อัปโหลดไฟล์ชุดใหม่ทับของเดิม (Add file → Upload files → Commit) รอ 1–2 นาที แล้วรีเฟรชหน้าเว็บ
