ติดตั้งแอป MJ ASSET

เลือกอุปกรณ์ด้านล่างเพื่อดูวิธีติดตั้ง
เปิดแอป เข้าใช้งานบนเว็บ
  1. เปิดหน้านี้ด้วย Google Chrome หรือ Microsoft Edge (ใช้ได้ทั้ง Windows และ Mac)
  2. กดปุ่ม ติดตั้งแอป ด้านบน — หรือกดไอคอน ติดตั้ง ที่ท้ายช่องที่อยู่เว็บ
  3. กด ติดตั้ง (Install) → แอปเปิดเป็นหน้าต่างของตัวเอง มีไอคอน MJ ASSET บนเดสก์ท็อป ทาสก์บาร์ และเมนู Start

ไม่เห็นปุ่มติดตั้ง? กดเมนู ⋮ (Chrome) หรือ ⋯ (Edge) → ติดตั้ง MJ ASSET / แอป → ติดตั้งไซต์นี้เป็นแอป

  1. เปิดหน้านี้ด้วย Chrome บนมือถือ (สแกน QR บนจอคอม หรือเปิดลิงก์ที่ได้รับ)
  2. กดปุ่ม ติดตั้งแอป ด้านบน — หรือเมนู ⋮ → ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก
  3. กด ติดตั้ง → ไอคอน MJ ASSET จะอยู่บนหน้าจอโทรศัพท์ เปิดได้แบบเต็มจอ

กดไอคอนแอปค้างไว้ → สแกน QR เปิดกล้องสแกนสติกเกอร์ได้ทันที

  1. เปิดหน้านี้ด้วย Safari (บน iPhone / iPad ต้องใช้ Safari เท่านั้น)
  2. กดปุ่ม แชร์ (iPhone อยู่ด้านล่างจอ · iPad อยู่มุมขวาบน)
  3. เลื่อนลงแล้วกด เพิ่มไปยังหน้าจอโฮม → กด เพิ่ม
  4. เปิดแอป MJ ASSET จากไอคอนบนหน้าจอโฮม แล้วเข้าสู่ระบบด้วย Gmail ของหน่วยงาน

ถ้าเปิดจาก LINE หรือ Chrome อยู่ ให้กด คัดลอกลิงก์ ด้านบน แล้วไปวางใน Safari

สแกน QR ตรวจนับใช้กล้องมือถือ/iPad สแกนสติกเกอร์ เปิดข้อมูลทรัพย์สินทันที
อัปเดตเองอัตโนมัติระบบปรับปรุงเมื่อไร แอปทุกเครื่องได้เวอร์ชันล่าสุดเอง
ปลอดภัยตามสิทธิ์เข้าสู่ระบบด้วย Gmail หน่วยงาน เห็นเฉพาะข้อมูลที่ได้รับสิทธิ์
